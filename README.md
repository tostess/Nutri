# Colo · nutrição materno-infantil

Protótipo navegável do app de atendimento de uma nutricionista materno-infantil, com duas visões:

- **Nutricionista**: gestantes, lactantes e bebês/crianças. Crescimento (SBP/OMS), ganho de peso gestacional (curvas brasileiras), necessidades (DRI/NASEM 2023), fórmula e diluição, plano alimentar, diário e cadastro.
- **Família/paciente**: plano de mamadas, plano alimentar, diário com sintomas, consultas.

Arquivo único (`index.html`), sem backend. Os dados de exemplo são fictícios e o que for digitado fica só no navegador de quem usa.

Abra com `#familia` no fim do endereço para entrar direto na visão da paciente.
